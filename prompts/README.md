# DaVinci Resolve MCP Prompt Templates

This directory contains example prompt templates for using the DaVinci Resolve MCP server with Claude Desktop.

## Available Templates

### Basic Video Editing Workflow
`basic_editing.md` - Simple video editing tasks for beginners

### Color Grading Session
`color_grading.md` - Professional color grading workflow

### Batch Processing
`batch_processing.md` - Automated processing of multiple files

### Audio Post-Production
`audio_post_production.md` - Audio editing and mixing workflow

## Usage

Copy these templates into Claude Desktop or use them as inspiration for your own custom prompts.

## Template Variables

- `{input_folder}` - Path to input media files
- `{output_folder}` - Path to output destination
- `{project_name}` - Name for the new project
- `{frame_rate}` - Video frame rate (e.g., 24, 30, 60)
- `{resolution}` - Video resolution (e.g., "1920x1080", "3840x2160")
